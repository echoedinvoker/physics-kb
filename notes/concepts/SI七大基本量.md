# SI七大基本量

> SI 制的七大基本量：長度(m)、質量(kg)、時間(s)、發光強度(cd)、溫度(K)、電流(A)、物質計量(mol)。

## 背景知識

理解此概念前需要先掌握：
- [[國際單位系統]]

## 詳細說明

| 基本量 | 單位名稱 | 單位符號 |
|--------|---------|---------|
| 長度 | 公尺 | m |
| 質量 | 公斤 | kg |
| 時間 | 秒 | s |
| 發光強度 | 燭光 | cd |
| 溫度 | 克耳文 | K |
| 電流 | 安培 | A |
| 物質計量 | 莫耳 | mol |

所有其他物理量（如速度、力、能量）都可以用這七個基本量的組合表示（見[[因次定理]]）。

## 常見錯誤

> 此段為 LLM 增強內容，教材原文未提及。

1. **錯誤認知**：力（牛頓）是基本量
   - 正確理解：力是導出量，N = kg·m/s²，由質量、長度、時間三個基本量導出
