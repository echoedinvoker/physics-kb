# 單位前綴

> SI 制使用標準前綴表示不同量級，從 atto(10⁻¹⁸) 到 tera(10¹²)，常用有 nano/micro/milli/kilo/mega/giga。

## 背景知識

理解此概念前需要先掌握：
- [[國際單位系統]]

## 詳細說明

| 前綴 | 符號 | 倍數 | 前綴 | 符號 | 倍數 |
|------|------|------|------|------|------|
| atto | a | 10⁻¹⁸ | kilo | k | 10³ |
| femto | f | 10⁻¹⁵ | mega | M | 10⁶ |
| pico | p | 10⁻¹² | giga | G | 10⁹ |
| nano | n | 10⁻⁹ | tera | T | 10¹² |
| micro | μ | 10⁻⁶ | | | |
| milli | m | 10⁻³ | | | |

例：1 nm = 10⁻⁹ m, 1 GHz = 10⁹ Hz, 1 kg = 10³ g

## 常見錯誤

> 此段為 LLM 增強內容，教材原文未提及。

1. **錯誤認知**：m（milli, 10⁻³）和 M（mega, 10⁶）大小寫沒差
   - 正確理解：大小寫區別非常重要，mW 是毫瓦，MW 是百萬瓦
