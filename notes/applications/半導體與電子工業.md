# 半導體與電子工業

> 半導體技術從矽晶體出發，經電晶體、積體電路到 CPU，使電子產品走向輕薄短小。

## 原理

[[半導體]]的導電性可被精確控制（通過摻雜和電壓）。利用這個特性，科學家製造出電晶體——一種微小的電子開關。1958 年，多個電晶體被整合在一個晶片上，形成[[積體電路]]（IC）。

## 發展歷史

1947 年：貝爾實驗室發明電晶體，取代笨重耗電的真空管
1958 年：基爾比發明積體電路，一個晶片 = 完整電路
此後：IC 不斷微縮，今日一個 CPU 包含數十億個電晶體

## 日常應用

- 智慧手機、電腦、平板等所有電子設備的核心
- 太陽能電池利用半導體的光電效應
- LED 燈利用半導體的電致發光
- 感測器（溫度、壓力、光線等）
