# Q-nuclear-fission-energy-01

## 題目

鈾235的分裂：n+U→Ba+Kr+3n，質量分別為：U:235.043924u, Ba:142.920483u, Kr:89.919528u, n:1.008665u
(1)一個鈾235分裂後所釋放的能量為何？
(2)若1kg碳燃燒釋放的能量為3.29×10⁷焦耳，即1kg鈾所釋放的能量為碳的幾倍？

## 答案

(1)2.78×10⁻¹¹ J
(2)2×10⁶ 倍

## 解析

(1)質量虧損Δm = (235.043924+1.008665)-(142.920483+89.919528+3×1.008665) = 0.186603u
Δm = 0.186603×1.66×10⁻²⁷ kg = 3.098×10⁻²⁸ kg
E = Δmc² = 3.098×10⁻²⁸×(3×10⁸)² = 2.78×10⁻¹¹ J

(2)1kg鈾含原子數 = 1000/(235×1.66×10⁻²⁷) = 2.56×10²⁴
總能量 = 2.56×10²⁴×2.78×10⁻¹¹ = 7.12×10¹³ J
比值 = 7.12×10¹³/3.29×10⁷ ≈ 2×10⁶
