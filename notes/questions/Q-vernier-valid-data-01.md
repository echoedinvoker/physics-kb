# Q-vernier-valid-data-01

## 題目

設游標尺上的20個刻度等於主尺上39個刻度(即39mm)，則下列那些數據為利用此游標尺讀得者？
(A)1.20×10⁻²m (B)6.582cm (C)0.11175m (D)2.45mm (E)42.5mm

## 答案

CD

## 解析

此[[游標尺]]精確度=2mm-39/20mm=2-1.95=0.05mm
讀數末位應在0.05mm→即末位為0或5（以0.05mm為單位）
(A)1.20×10⁻²m=12.0mm→末位在0.1mm精度，不對
(B)6.582cm=65.82mm→末位在0.01mm精度，過精
(C)0.11175m=111.75mm→末位在0.05mm精度✓
(D)2.45mm→末位在0.05mm精度✓
(E)42.5mm→末位在0.5mm精度，不對
